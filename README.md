# HealthyTeeeeth — страницы стоматологической клиники

Учебный проект Skillbox: статические страницы сайта стоматологической клиники HealthyTeeeeth.
Реализованы страницы «О клинике» и «Лечение зубов во сне» на HTML и SCSS.

## О проекте

В проект входят страницы [«О клинике»](./about.html) и [«Лечение зубов во сне»](./sedation.html).

### Возможности

- Общие шапка, навигация, хлебные крошки и подвал на обеих страницах.
- На странице «О клинике»: фотографии с подписями, текстовые разделы, цитата, список преимуществ и таблица вакансий.
- На странице лечения под седацией: информационные разделы, список преимуществ и таблица услуг с длительностью и стоимостью.
- Стиль классов организован по БЭМ: блоки (`header`, `breadcrumbs`, `text-block`, `footer`), элементы с `__` и модификаторы с `--`.
- Для страницы седации используется модификатор `.text-block--sedation`: заголовки и ячейки таблицы оформлены шрифтом Nunito Sans, а ширины столбцов таблицы заданы как 400, 200 и 200 px.
- Главное изображение страницы седации получает арочную обрезку через `clip-path`, ссылающийся на SVG-клип `arc-clip` в `images/sprite.svg`.

## Стек технологий

- HTML5.
- SCSS с модулями `global/` и `blocks/`.
- CSS — готовые стили страниц в `style.css`.
- Rubik и Nunito Sans — локальные шрифты `.woff2`.
- SVG-спрайт для логотипа и иконок.

## Структура папок

```text
.
├── fonts/              # Файлы Rubik и Nunito Sans
├── images/             # Фотографии и SVG-спрайт
│   └── sprite/         # Исходные SVG-файлы
├── scss/
│   ├── blocks/         # SCSS-компоненты, включая стили седации
│   ├── global/         # Шрифты, переменные и базовые стили
│   └── style.scss      # Главный SCSS-файл
├── about.html          # Страница «О клинике»
├── sedation.html       # Страница «Лечение зубов во сне»
├── style.css           # Готовые стили, подключённые в HTML
├── style.css.map       # Карта исходников CSS
├── CHANGES.md          # Сведения о доработках
└── LICENSE             # Лицензия MIT
```

## Как запустить

Сборка и установка зависимостей для просмотра страницы не требуются. Откройте `*.html` в браузере или используйте расширение **Live Server** в VS Code.
